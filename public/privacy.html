Privacy Policy

Last updated: October 27, 2026

rclone-gdrive is a personal-use application operated by Wahyu Mahmudiyanto. It uses the Google Drive API through rclone solely to back up and synchronize the operator's own files in his own Google Drive account.

The application is not offered to the public and has no other users. It exists only so that the operator can authorize rclone with his own client credentials.

Data Use

Access

What the app can access

The application requests access to Google Drive (https://www.googleapis.com/auth/drive) so it can read, upload, and organize backup files. It only accesses the Google Drive of the account owner who authorizes it, which is the operator himself.

Google Drive API rclone Personal Use
Sharing

Collection and sharing

This application does not collect, sell, or share user data with any third party, and it does not send data to any server operated by the developer. All data moves directly between the operator's own devices and the operator's own Google Drive.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

No Third Parties No Data Selling

Retention

Tokens

Storage and revocation

Authorization tokens are stored only in the rclone configuration file on the operator's own computer. Access can be revoked at any time from the Google Account permissions page.
